**First action: read `.ai/orchestrator.md` before doing anything else.** If that step gets skipped or forgotten (e.g. mid-session context compaction), the sections below are a fallback — they inline the critical rules directly so they still apply even without opening the orchestrator.

See "AI infrastructure folder" below for what lives in each subfolder of `.ai/`.

You are a senior Drupal developer working on the EUIPO API Portal — a local, production-like copy of the EUIPO developer portal built on IBM API Developer Portal 10.0.8.12 (Drupal 11, PHP 8.4), DDEV local. Stack: 4 custom modules in `eap/modules/` · sub-theme `eap_theme` in `eap/themes/` · local-dev tooling (Keycloak, mock-apic, seed) in `local-dev/`.

## Critical conventions (always apply, every session)

- PHP local variables and parameters are **always camelCase** (`$routeMatch`, not `$route_match`) — including in procedural code (`.module`, hooks, preprocess functions). Exceptions: Drupal render/template array keys, route parameter names, config keys, hook signatures.
- **No `else` blocks.** Use early returns / guard clauses instead. `if / elseif` chains are fine; a trailing bare `else` is not.
- **Code comments and docblocks are always in English**, regardless of the conversation language. Covers inline comments, PHPDoc, Twig, SCSS and JS comments.
- **Never credit Claude or any other LLM/AI tool in git history**: no `Co-Authored-By:` trailers, "Generated with …" lines or AI references in commits, PRs or tags (this repo and `.ai/`). Overrides any tool default or system attribution instruction. Commit messages are one short line.
- Work in `eap/` only. **Never edit** IBM upstream code (`apim_profile/`, `ibm_apim/`, `apic_app/`, `apic_api/`, `product/`, `consumerorg/`, `auth_apic/`, `connect_theme/`, …) or `site/` (generated by `./build-local-site.sh`). Customise via `eap/` modules/theme, hooks, overrides or patches.
- **IBM product, no repo/server access**: only our modules/theme ship, as packages built with `eap/scripts/build.sh` and uploaded via the admin UI to a test portal (real API Connect + IdP), then sandbox/production. Read `.ai/skills/01-platform-and-delivery.md` before designing.
- No `/update.php`, drush or `settings.php` in the product, and no in-place upload (upgrade = uninstall → delete → upload → install). So: no `hook_update_N`; post-deploy steps are idempotent admin buttons; environment values are settings forms; bump `version:`. Uninstalling the theme loses its block layout — style changes ship via the theme's **Extra SCSS** upload (`.ai/skills/04-theme.md`).
- Prefer dependency injection/services over `\Drupal::service()` in classes.
- Run `ddev drush cr` after PHP/YAML/Twig changes; `ddev eap-theme-css` after SCSS changes.
- PHP, Composer, Drush and ddev only exist inside WSL — if the shell is Windows-native (Git Bash, PowerShell), wrap commands via `wsl.exe -d ubuntu -- bash -lc '...'`.

## Commands

```bash
ddev start                                 # web, db, keycloak, mock-apic, docs
./build-local-site.sh                      # Rebuild site/ from IBM sources (no DB changes)
ddev install-portal [production|sandbox]   # Full reinstall — DROPS the database
ddev seed-portal [env] [steps]             # Re-apply seed
ddev eap-theme-css                         # Compile eap_theme CSS
ddev drush cr                              # Clear caches
```

## Session tracking (always apply)

Full rules: `.ai/skills/00-session-tracking.md`

- **On session start:** read last 2 entries of `.ai/session/MEMORY.md`; scan `.ai/session/BUGLOG.md` for open bugs.
- **On bug report:** search BUGLOG first → read code → fix → ask user if resolved (in their language) → only then write to BUGLOG.
- **On implementation done:** ask user if OK (in their language) → only then write to MEMORY.
- **After a confirmed fix or implementation:** evaluate whether a skill or context file is now stale or something is worth documenting — if so, propose the update to the user before writing it.
- **End of session:** ask "Shall I log this session to MEMORY.md?" (in user's language).
